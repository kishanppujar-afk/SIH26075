  • Quarantined Sandbox: Practice quiz attempts (is_practice=True) strictly protect official readiness scores.

TECHNICAL APPROACH

ARCHITECTURE, TECH STACK & END-TO-END IMPLEMENTATION PIPELINE

[Team Name]

Technologies To Be Used

Specifications

  • Modern Frontend: React 18/19, Vite, Tailwind CSS, Lucide Icons, Recharts (Radar, Heatmaps).
  • Asynchronous Backend: FastAPI (Python 3.12), SQLAlchemy 2.0 ORM, Pydantic v2 data models.
  • Sovereign AI Engine: Ollama local daemon hosting gemma3:4b (LLM reasoning) & nomic-embed-text (embeddings).
  • Vector Retrieval: Sliding-window semantic chunker (500 chars, 100 overlap) with Cosine Similarity search.
  • Enterprise Security: JWT bearer authentication, Passlib/Bcrypt password hashing, Role-Based Access Control.
  • Test Coverage: 41/41 unit & integration tests passing in pytest (scoring isolation, RAG, calibration).

Methodology & Implementation Process

6-Stage End-to-End Workflow

01
Ingestion: Upload official MoSPI circulars, manuals, or survey SOPs (PDF/DOCX/TXT).
02
Chunking & Embeddings: Extracts semantic chunks; generates 768-dim embeddings via local Ollama.
03
Grounded MCQ Generation: Cyclically applies 5 cognitive angles with verbatim source citations.
04
Admin Studio Review: Faculty curates questions, edits distractors, and publishes practice sets.
05
Quarantined Practice: Officers practice without penalty (is_practice=True) to build fluency.
06
Cadre Telemetry & iGOT: Maps deficits to 53 NSSTA courses with automated promotion tracking.

FEASIBILITY AND VIABILITY

OPERATIONAL FEASIBILITY, ZERO-LICENSE ECONOMICS & RISK MITIGATION

[Team Name]

Analysis of Feasibility

Operational & Economic Viability

  • Fully Functional MVP: Production-grade system with 47 REST APIs, 12 seeded Indian Statistical Service profiles, and 53 NSSTA courses.
  • Zero-License Cost: 100% open-source stack (FastAPI, React, Ollama, SQLite). Zero third-party API dependencies or recurring cloud fees.
  • Workstation Footprint: Efficiently executes on standard NIC/MoSPI office laptops (8GB–16GB RAM) without requiring cloud servers.
  • Frictionless Onboarding: Web-based single-page application requires zero client-side installation for field officers.

Potential Challenges, Risks & Mitigations

Defensive Engineering Strategies

1. Risk: LLM Hallucinations in Assessment MCQs Mitigated

Strategy: Single-chunk strict context bounding; forces source snippet citation displayed alongside every question.

2. Risk: Distortion of Official Readiness Scores Mitigated

Strategy: 1-question evaluations capped at max 80%; requires 2+ questions for 100%; practice attempts quarantined via is_practice=True.

3. Risk: Sensitive Government Data Leaks Mitigated

Strategy: 100% on-premises execution via local Ollama runtime; zero external API egress or third-party telemetry.

4. Risk: Low Field Officer Adoption Mitigated

Strategy: Low-stakes diagnostics; empathetic "Disha" AI mentor; seamless 1-click redirection to iGOT Karmayogi modules.
